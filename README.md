#  Battle Jet — Pygame Shooting Game

**Battle Jet** is a simple 2D shooting game written in Python using the **Pygame** library.  
The player controls a jet fighter that can move horizontally, shoot bullets, and fight against waves of enemy aircraft.

---

## �Features

- Player jet with adjustable speed and HP
- Enemy planes that move and shoot bullets
- Player bullets and enemy bullets with collision detection
- Health system and scoring
- Win/Lose conditions and restart logic (2000 score win the game, achieve 500, 1000 score damage increase 1 and refresh hp)

---

##  File Structure

Battle_Jet/

## control
A/D or ← / → to control player jet move left and right
Press 'Space' to shoot bullet
